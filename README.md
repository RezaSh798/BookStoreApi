# Book Store Api
A simple CRUD .net core project.

### Install dependencies
`dotnet restore`

### How to run project
Use following commands:

`dotnet run --project Src/BookStoreApi`
Or
`dotnet watch --project Src/BookStoreApi`.

### How to run tests
Use following command:

`dotnet test`

### Swagger
`http://localhost:3000/swagger/index.html`
